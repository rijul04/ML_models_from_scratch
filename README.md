# ML Models From Scratch

This repository documents my implementation of machine learning models from first principles, with the aim of developing a deeper understanding of the algorithms and mathematics behind modern machine learning.

For each model, I will:

* Study the underlying theory, mathematics, and optimisation techniques.
* Implement the model from scratch using **Python and NumPy**, without relying on high-level machine learning libraries.
* Implement core components such as forward passes, loss functions, gradients, parameter updates, and training loops where applicable.
* Train and evaluate the model on suitable datasets.
* Reimplement the same model using **PyTorch**.
* Compare the NumPy and PyTorch implementations to understand the abstractions and functionality provided by modern ML frameworks.

The goal is to move beyond simply calling library functions and gain a stronger understanding of how machine learning models operate internally, from numerical computation and optimisation to model training and evaluation.

## Technologies

* NumPy
* PyTorch
* Pandas
